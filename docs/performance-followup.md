# 后续性能优化

本轮以 `3c148e1` 为基线，继续测量上一轮滚动修复后的热点。

## 颜色解析

滚动刷新前实时检查语言服务是否支持 `textDocument/documentColor`。没有对应能力时，不进入插件昂贵的版本查询与请求准备；动态增加、移除能力时立即重新判断，不缓存客户端能力。

CSS 变量解析沿用锁定插件的原始规则，按缓冲区和文本版本缓存结果，也缓存不存在的变量。同一变量不再为每个可见使用位置反复全文查找。修改、撤销和文件重读会使缓存失效；卸载、重载与关闭适配层时清理。缓存只在滚动的同步绘制期间使用，原有即时编辑刷新入口继续保留。

真实插件回归计数：一个包含有效及无效变量的视口，全文扫描从 42 次降至冷缓存的 2 次；随后滚动到六个新视口，全文扫描为 0 次。无客户端、无颜色能力及移除能力后均不调用原 LSP 流程；动态获得能力后，同一缓冲区的两个视口合计调用一次。

此项仍保留上游对迟到 `documentColor` 回复缺乏版本过滤的限制，并未引入完整 LSP 结果缓存。
