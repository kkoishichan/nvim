# 保留原高亮的键盘滚动优化

2026-09-17，以 `6dbda23` 为基线，继续读取用户的 `transformer.py`：237 行、10,592 字节。文件内容未修改。

## 改动与范围

移除 Neoscroll 的默认按键接管及对应依赖，恢复 Neovim 原生分页、单行滚动和视口定位。原先半页动画配置为 `250 × 0.65 = 162.5 ms`，整页为 `450 × 0.65 = 292.5 ms`，逐行绘制和调度还会增加实际耗时。

Tree-sitter 启用方式、查询、主题和语法配色全部保留。没有采用传统 Vim 高亮替代，也没有加入试验中的查询缓存；后者在交错测量中收益不足以支持增加维护成本。

这次改动直接改善 `Ctrl-D/U/F/B`、`Ctrl-E/Y`、`zt/zz/zb`。`Ctrl-E/Y` 恢复单行滚动及计数；整页按键也恢复原生页间重叠和光标落点。插入模式下的补全、签名专用按键继续由原来的插件处理。

鼠标滚轮原本就没有经过 Neoscroll，因此本阶段不宣称额外改善了鼠标或触控板延迟。此前的高亮查询开销仍然存在，不能据此称整个编辑器已达到最小 Vim 配置的速度。

## 测量

Neovim 0.12.5，120 × 36 屏幕网格，同一个 Python 文件。完整配置按 AB/BA 两轮交错运行，每个按键每轮 6 次；每个场景先完成一次未计时滚动，用真实映射的最终视口作为终点。测量从输入按键到该视口与光标到位后的 UI flush，包含动画、高亮、插件及本地 RPC，不包含终端、桌面或物理输入设备。

| 按键 | 原配置中位数 | 当前中位数 |
| --- | ---: | ---: |
| `Ctrl-D` 半页 | 213.95 ms | 17.57 ms |
| `Ctrl-F` 整页 | 379.85 ms | 21.91 ms |

半页前后的目标视口和光标相同。整页恢复原生语义后，目标视口从第 87 行变为第 85 行，光标从第 103 行变为第 93 行；因此整页比较代表同一个按键的使用体验，而非完全相同位移的绘制微基准。样本较少，仅用于确认取消人为动画等待的效果。
