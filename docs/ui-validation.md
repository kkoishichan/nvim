# 窗口与工作区会话验收

正文最小空间来自 `preferences.json` 的 `ui.min_editor_width` 与 `ui.min_editor_height`，默认 40 列、8 行。侧栏共享剩余宽度，输出窗口共享底部区域；小屏无法同时保留两侧栏时，优先保留正在操作的侧栏，否则保留导航栏。继续不足时收起辅助面板。重新打开面板仍使用现有插件入口。

尺寸调整不会关闭正文窗口；修改中的面板不会被自动收起。隐藏终端会保留缓冲区和进程。用户手工建立过多正文分屏，或保护中的编辑面板占满屏幕时，不会为了满足尺寸数值而强制关闭它们。

`scripts/checks/layout_session.lua` 在完整配置中加载真实 Edgy，分别以 80×24、120×36、180×50 打开导航、AI、终端和诊断面板，检查正文至少 40×8；另验证修改中的面板仍存活，以及实际本地终端子进程在面板隐藏、会话保存和会话恢复后仍在运行。无头窗口几何检查不代表终端字体、颜色或远程输入体验已完成视觉验收。

会话现在明确保存整个编辑工作区，包括多个标签页及各自的工作目录和显式项目选择。首次保存按第一个正文标签页的项目命名；切到其它标签页不会创建另一份会话，恢复后继续使用选中的会话文件。会话不以某一个项目的 Git 分支代替整个工作区的身份。

仍使用 Persistence 原有目录和原生 `.vim` 会话格式，附带 `.vim.json` 项目元数据。旧 `.vim` 文件不需要转换即可加载，继续恢复其中的原生 `tcd`。元数据使用会话内容校验值，避免误套用不匹配的目录信息。保存会话不执行新的终端或 AI 命令，也不记录其进程；真实隐藏文件仍会保留在会话中。

恢复前若有未保存文件或可写目录编辑，会拒绝恢复并提示先处理这些修改。会话保存文件列表、布局和位置，不替代未保存内容的备份。会话列表会标出新格式记录的工作区及标签页数量；保存开关只有一个自动回调负责。

本轮两项目样例验证了多标签页目录与项目归属恢复、隐藏文件保留、面板名称与终端排除、旧会话兼容、未保存文件保护。全部会话、缓存和样例写入临时目录，没有覆盖个人会话。

复跑：`./scripts/check.sh layout_session`。终端输入及屏幕检查由 `scripts/ui-smoke.py` 留下 PTY 日志和窗口数据；其模拟 SSH 环境变量与无图片协议条件，不等同于连接一台真实 SSH 主机。

2026-09-05 的真实 PTY 检查使用 `TERM=xterm-256color`，三个尺寸均验证了键盘触发保存、Ctrl-Left 调整宽度、Ctrl-/ 打开及切回终端、分两次 Escape 离开终端模式，以及 Alt-Space 派发。传统终端把 Ctrl-/ 编码为同一控制字节 `<C-_>`，已增加对应别名。缓冲区补全菜单实际出现的单次耗时依次为 20.5、13.7、11.6 ms；这些数字是本机样例观察值，不是延迟保证。

`ui_themes` 检查四个现有主题的实际 Normal 与 Popup 颜色，正文对比度均达到 4.5。PTY 证据保留在本轮 `/tmp/nvim-ui-smoke-z2w6kwb5/results.json` 及各尺寸的 `terminal.log`、窗口 JSON；可用 `scripts/ui-smoke.py` 重新生成。真实 SSH 主机、输入法组合键、终端字体和所有图片协议仍超出这些自动检查的证明范围。
